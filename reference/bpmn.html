Tema BPMN

Los elementos de BPMN con los roles, el radio y el trazo de AGCS

Tema para bpmn-js 18.31.1, el editor y visor de BPMN de bpmn.io. Son dos archivos en ui/bpmn/: agcs-bpmn.css viste el lienzo, la paleta, el context pad y el menú emergente; agcs-bpmn.js dibuja los elementos con los roles de tokens/colors.css, deja las esquinas rectas, el trazo en 1,5 px y pinta el único lime del diagrama. Cómo copiarlo a una app está en docs/bpmn.md.

Esta página carga módulos de JavaScript y no funciona abierta como archivo. En la raíz del repo, corre python3 -m http.server 8000 y abre http://localhost:8000/reference/bpmn.html. Necesita conexión para cargar bpmn-js desde unpkg.

Uso

<div id="diagrama" class="agcs-bpmn"></div>

import BpmnModeler from "bpmn-js/lib/Modeler";
import { agcsBpmnConfig, agcsBpmnModule, setHighlight } from "./agcs-bpmn.js";

const container = document.getElementById("diagrama");
const modeler = new BpmnModeler({
  container,
  ...agcsBpmnConfig(container),
  additionalModules: [agcsBpmnModule],
});
await modeler.importXML(xml);
setHighlight(modeler, "Task_Revisar");   // el único lime del diagrama

Modo claro

Todos los diagramas de esta página son editables. Pasa el puntero sobre un elemento: baja a opacidad 0,7. Selecciona uno para ver el context pad.

Normal

Catálogo de elementos: no forman un proceso

Seleccionado

Contorno recto en tinta. En la app se selecciona un elemento a la vez; aquí se muestran todos con ese contorno. Con varios seleccionados, el contorno pasa a --ink-3

Error

Trazo en --text-error y una etiqueta escrita. El color nunca va solo

Proceso: Apertura de cuenta digital

Un lime: «Revisar alertas de riesgo», la revisión manual que fija el plazo. Ejemplo inventado

Modo oscuro

Los mismos diagramas dentro de un bloque con data-mode="dark". El tema lee los roles del contenedor, así que toma los del modo oscuro. Sobre negro, la marca del lime es lime.

Qué no se cambia

  • El logo de bpmn.io, abajo a la derecha de cada diagrama. La licencia de bpmn-js pide que se vea siempre. El tema solo le da el color --ink-2.
  • El radio 0, la sombra 0 y el trazo de 1,5 px.
  • Los colores por rol. Los colores que traiga un archivo .bpmn se guardan en el XML y no se pintan.
  • Un solo lime por diagrama, con su marca negra.
